# Pigułka — Centrum rozwoju KAIROX
Statyczna wersja aplikacji do nauki, powtórek i testów. Publikacja: GitHub Pages, gałąź `main`, folder `/`.

Uruchomienie lokalne: `python3 -m http.server 8785` i otwarcie http://localhost:8785.

Postępy, wizyty i archiwizacja zapisują się w localStorage tej przeglądarki. Nie synchronizują się między urządzeniami. Wyczyszczenie danych witryny usuwa postępy. Repozytorium zawiera treści i pytania, bez prywatnej historii lokalnej aplikacji.

Wersja źródłowa z serwerem Python pozostaje w osobnym projekcie Centrum rozwoju. Aktualizując treści online, zachowaj identyfikatory pigułek i zgodność banków pytań.
